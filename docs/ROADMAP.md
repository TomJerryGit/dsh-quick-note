# 管理台功能规划（全面版）

> 插件：`@local/dsh-quick-note`（侧栏「管理台」）· 当前版本 v1.12.0
> 本文是功能广度/深度、UI/交互、Agent 集成、数据安全与技术质量的完整规划，按优先级分批实施。
> 每轮完成后更新「已交付」与「基线」，路线图条目按实际价值重排。
> **最新全面审计、官方插件借鉴与下一阶段需求提案见 [NEXT-FEATURES.md](NEXT-FEATURES.md)（2026-11-05）。**

## 1. 现状总览

| 维度 | 现状 |
|---|---|
| 模块 | 知识（笔记 + 复习/SM-2） / 计划（任务：列表 / 看板 / 日历 + 未来 7 天时间轴） / 健康（指标+用药+参考范围） / 自定义记录类型与视图 |
| 聚合视图 | 概览（概览仪表盘 + 全部跨模块表） / 记录 / 分析（价值 / 用量 / 系统 / Harness 版本管理） / 设置（含备份、外观、提醒） |
| Agent 工具 | `quick_note_search` / `create` / `update` / `complete` / `batch` / `type` / `workspace`（list/rate/snapshot/report/archive） |
| 数据层 | 单 JSON 原子写 + 串行队列；乐观锁 If-Match/ETag；条目 rev 合并；软删除墓碑；只读/备份路由 loopback token；自动滚动备份（10 份） |
| UI | 设计令牌 + v3 样式层；Hero/标签图标/SectionHead/EmptyState/骨架屏/密度切换/强调色/KPI 迷你趋势线/拖拽动画/命令面板 |
| 测试 | Host 69 项 + Client 53 项回归（无浏览器依赖，`npm test` / Electron-as-node） |

## 2. 差距分析（按模块）

| 模块 | 广度缺口 | 深度缺口 | UI/交互缺口 |
|---|---|---|---|
| 笔记 | 无文件夹/标签页视图、无归档 | 无 Markdown 预览、无反向链接、无版本历史 | 无阅读模式、无大纲 |
| 任务 | 无重复任务、无子任务、无依赖 | 无清单步骤、无统计（完成率/周期） | 无日历视图、无泳道、无批量改截止 |
| 复习 | 无「全部/新卡/到期」学习模式 | 无预测曲线、无遗忘风险、无目标完成历史 | 无快捷评分键、无全屏专注模式 |
| 健康 | 无参考范围、无异常规则 | 无依从性统计、无多指标相关分析 | 异常高亮、单位换算 |
| 记录 | 无聚合/仪表盘、无关联 | 无字段公式、无 CSV 导出 | 无看板/分组视图 |
| 数据 | 无完整备份/还原、无自动滚动备份 | 无导入合并策略、无迁移版本 | 备份预览 |
| Agent | 无批量工具、无标签筛选 | 无「重复任务/子任务」工具面 | 工具输出结构化摘要 |
| 全局 | 无日历/时间轴视图 | 无跨模块全文搜索历史 | 快捷键帮助面板、最近访问 |

## 3. 路线图

### P0（已完成 ✅）
1. ✅ **数据安全**：完整备份（items/settings/reviews/types）导出/导入 + 两步确认恢复 + 自动滚动备份（最近 10 份）
2. ✅ **任务深度**：检查清单、重复任务（daily/weekly/monthly + 完成派发下一次）、完成统计（今日/本周/逾期）、快捷截止
3. ✅ **复习深度**：学习模式（到期/新卡/全部）、键盘快捷评分（1/2/3/空格/U/Esc）、专注模式、每日目标
4. ✅ **全局体验**：命令面板（Ctrl/⌘K）、置顶收藏、快捷操作
5. ✅ **健康深度**：指标参考范围与正常/偏高/偏低徽标、异常高亮
6. ✅ **Agent 广度**：`quick_note_batch` 批量工具、tag/overdue/dueWithinDays 过滤、checklist/repeat 参数

### P0+（下一批）
1. ✅ 任务日历视图（due + 复习 + 用药）—— v1.4.0 已交付

5. 快捷键帮助面板与可自定义快捷键

## 4. 技术质量目标

- **性能**：面板首屏 < 1s；1 万条以内列表滚动 60fps；价值报告缓存命中 < 100ms；写入并发冲突可自动恢复
- **稳定性**：所有写入幂等/可重试；崩溃后 mirror + 备份可恢复；软删除可恢复
- **可访问性**：全键盘可达（命令面板/列表/编辑器/复习）、aria 完整、reduced-motion
- **测试**：每项新功能至少 1 条 Host 或 Client 回归；核心数据路径覆盖冲突/软删除/备份
- **体积**：client.js 单文件 < 640KB（v1.18.0 起，含构建产物）；字典键 100% 使用率、无字面色
